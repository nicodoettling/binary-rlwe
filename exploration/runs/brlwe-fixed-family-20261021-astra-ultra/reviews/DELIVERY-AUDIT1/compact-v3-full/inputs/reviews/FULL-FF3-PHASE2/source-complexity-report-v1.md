# Source, representation and complexity review

The source record for this phase is internal and exact:177 hashed author files plus the root affine and symmetry files listed in the input manifests. The review reads statements AND proofs and reconstructs each used elementary algebra/probability step. It does not import an external unnamed theorem as a new hardness premise. Cyclotomic irreducibility, Smith-form divisibility, Hadamard, finite DP, TV contraction, Bayes guessing and the finite Farkas implication are proved or reduced to their explicit elementary identities in full-report-v1.md. Historical main reductions are not recertified wholesale.

ENUM uses polynomial arithmetic on n-dimensional residues of bit size logQ for EACH of2^n binary candidates. Streaming memory is polynomial, but its worst-case arithmetic work is O(2^n poly(n,logQ)). Exact target DG sampling is an additional mathematical operation; a finite implementation must supply bounded samplers and add k*xi for total per-output approximation error xi. No actual-secret advice, unique-decoder oracle, factorization oracle or short-vector oracle is an input. Polynomial-value sigma_Q controls the tail prefactor. A supplied prime Q may have polynomial value for the displayed family; prime generation is not inferred for arbitrary extra number-theoretic constraints. Parameter choices have to pay all explicit encodings. Neither uniqueness nor statistical target identifiability is a polynomial-time recovery algorithm.

The corrected ENUM errors are negligible functions that remain negligible after multiplication by every fixed polynomial k for the SAME target family. This differs from the inherited FIXED-MAIN fixed-b,c window, but only at the statistical level. The cost2^n prevents an all-PPT fixed-family reduction. Choosing target parameters before sample/advantage exponents does not itself solve that cost. A future approximate sampler would need its accuracy set to dominate the intended sample count/advantage budget; a fixed inverse-polynomial error does not automatically support every polynomial exponent.

The deterministic compressed-selector theorem is an information bound with no efficiency assumption on the target estimator. L is the ACTUAL number of classes, M is the ACTUAL maximum rejection weight, and the expected trial count isM. A vector of n low-bit coordinates can have exponentially many classes. Adding a fixed number of polynomial-value statistics gives polynomial L; adding a growing number need not. Precomputed advice/table construction and encoding are not free for an algorithmic conclusion. The full rank retained by ENERGY/JOINTRANK is outside the compressed-only factorization premise, regardless of how few coarse energy classes exist. The optional randomized-class v1 clause needs the explicit fresh-state repair before its claims can be used.

Energy DP is polynomial in the NUMERIC alphabet sizes Q,q and in squared maximum entry magnitude B², not just in logQ or logB. Its O(n²B²Q) count additions use O(nlogQ)-bit numbers. Lexicographic ranking, unranking and pair ranking preserve this bound up to polynomial factors. An exponential shell cardinality is harmless when only its polynomial-length binary count is stored and a uniform rank is sampled. This does not make enumeration of an exponential number of shell indices or table states harmless. A rational h table with polynomially many entries of polynomial bit length gives exact expected polynomial-time sampling after clearing denominators; worst-case bounded runtime requires caps and explicit TV losses. An arbitrary real h gives only a mathematical kernel unless a suitable approximating row sampler is supplied. The claim explicitly says so.

COMPACT samples a uniform cube edge by choosing i and n-1 bits; the exponential edge count is not enumerated by that sampling operation. Ring arithmetic and monomial inversion are polynomial in n and log moduli. Computing the class, all relevant rational weights, rejection coins, H samples and their table descriptions must be efficient to conclude expected polynomial cost inM. The finite n2 table has maximumG<3, but no general-n value/encoding/constructibility bound follows. JOINT-RANK's47 entries and COMPACT's33 entries are fixed finite exact witnesses, not uniformly generated asymptotic families. Their finite source coefficient law(7/8,1/16,1/16) and target law(3/4,1/4) are not Gaussian proxies.

TWOEVENT's scalar wrapped-normalizer formulas define exact real numbers and valid probability rows. Ideal rejection has mean<=3/2 in the displayed regime; evaluating transcendental acceptance probabilities or sampling the proposals is not charged by that ideal count. A bounded finite approximate implementation needs rigorous likelihood/normalizer evaluation, proposal error and retry caps. None is supplied by the Gaussian existence note, and none is silently inferred here. ENERGY's wrapped-to-truncated comparison explicitly pays actual DG tails in both endpoints.

BOUNDED-AFFINE uses coefficient Euclidean norms and RAW finite second moments; no canonical-norm scaling is being imported from C8. It is an inequality about distributions and can use tests depending on retained S. There is no claim that the maximizing eigenvector test is an efficient unlabelled distinguisher. The modulo conclusion needs strict2R<q, not merely polynomial bit length of R. For inverse-polynomial trC and polynomial-value R the displayed positive lower bound is inverse polynomial only when the stated tail deductions are smaller. A nonpositive lower bound has no force.

The root finite symmetry systems are entirely finite n4 rational-law models. Complete matrix construction has exponential-in-n state spaces; its44.46s fixed-n check is not an asymptotic algorithm. Farkas witnesses prove infeasibility of exactly the reconstructed systems. The numerical primal ERROR and prior UNKNOWN remain distinct from the successful exact dual proof. No absence of a feasible table in these models proves source hardness, a reverse DGS implication, or a universal barrier. Standard ideal basis input restrictions remain unchanged because no phase2 kernel claims to solve an arbitrary ideal-lattice task from extra advice.

All actual experimental resources are separately recorded:120s timeouts;2GiB for exact certificate reconstruction and512MiB for probability/ENUM controls; no seeds, no floating probability aggregation, no optimizer in reviewer jobs.
