## Supported behavior and remaining limits

The output-root calculation and relative hash paths are consistent. The pinned draft-v4 digest matches, the programme extraction markers exist, and the audited mathematical block has SHA-256 `8ccbc7dfe1de149c1290732fef150e7fdaf70b1aae1cffc86c7e76bb0490d7ba`. The overlay hash logic hashes staged bytes for changed artifacts, then updates the termination-certificate record after adding commit metadata. The manifest excludes itself and the identified live files. Published data are rehashed before manifest/marker publication.

The finalizer does not call a goal mutation API, start a service or run an experiment. It requires the goal to remain active and uses native counter differences from the preserved zero baseline. Its wording explicitly excludes receipt-writing and final-response work after the saved counter observation, and does not claim backend billing or weekly quota usage. FF achievement and exhaustion remain false. Future graceful/hard shutdown and host-wide cleanup remain unobserved. The current `final.md` and `closeout-plan-v1.json` correctly describe closeout as pending before its scheduled execution.

The mechanism supplies atomic replacement of individual files and a last completion marker; it is not an all-or-nothing filesystem transaction or a crash-recovery proof. An unexpected I/O interruption can leave some data published without the marker. Success therefore requires a successful tool result, the final marker and matching manifest bytes; a standalone `DELIVERED` sentence is insufficient. No fault injection or execution with fabricated receipts was performed. This qualification is not an identified failure of the planned run.

Index v3 is intentionally to be generated after this additive seal. The final worker-stop, process/agent observations, native-goal receipt, 295-minute checkpoint and publication result are likewise future inputs. Their absence during this review is not an overdue gate and this review does not pre-certify their eventual values. Mathematical acceptance and the asserted 28 accepted auxiliary/source scopes remain the responsibility of their existing exact review records, not this operational source check.
