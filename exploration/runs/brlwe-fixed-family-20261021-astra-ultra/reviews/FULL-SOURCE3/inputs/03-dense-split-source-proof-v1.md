# SV-DENSE-SPLIT-v1 author proof

All primes split completely and are odd, so the displayed factors are distinct maximal ideals of norm p. CRT gives R_n/J_n=F_p^t as an additive group and ring, with exponent p and index p^t. By the definition of t, t*log2(p)<=rho*n. Since ell<=log2(p)+1 and t>rho*n/ell-2, we have t*log2(p)>=rho*n*log2(p)/ell-2*log2(p)>=rho*n/2-O(log n). The upper bound is rho*n. Hence the index is exponential and t tends to infinity.

The Galois group G=(Z/(2n)Z)^* is a 2-group acting freely and transitively on the completely split prime ideals over p. If H is the stabilizer of J_n, it preserves the set of its t prime factors. Every H-orbit in this set has size |H|, because the action on each split prime is free. Thus |H| divides the odd integer t; consequently H is trivial.

For the standard embedding Y=X^(n/g), the j-th selected prime restricts to evaluation at beta^(2j+1), where beta=alpha^(n/g) has order 2g. Among j=0,...,t-1 these restricted roots have exactly min(t,g) distinct values, since their period is g. Intersecting J_n with R_g requires vanishing at precisely these distinct roots modulo p. The corresponding CRT quotient has dimension min(t,g) over F_p, proving d_g=p^min(t,g). This uses simultaneous vanishing; duplicate restricted roots contribute no extra multiplicity, because the original ideal is squarefree and all primes are unramified.

If g<=t then d_g=p^g>=2^g and g is infeasible. If g>t then d_g=p^t, feasible exactly when g>t*log2(p). The full degree g=n is feasible because t*log2(p)<=rho*n<n. Thus every feasible standard subfield has the same index p^t, proving d_*=p^t. The optional arbitrary-subfield conclusion follows only after invoking the exact SV-ALL-SUBFIELDS inequality d_*<=d_all^2; it is not needed for the standard-chain counterexample.

An effective polynomial-value split prime family is supplied by the same effective Linnik construction already used for auxiliary prime families: fixed congruence classes can enforce p>=n^4 while keeping p polynomial in n. A primitive 2n-th root can be found by scanning elements of F_p, testing alpha^n=-1; because n is a power of two, this is exactly order 2n. Polynomial numeric p permits deterministic exhaustive search. Compute the monic polynomial F(X)=product_(j<t)(X-alpha^(2j+1)) over F_p. The ideal is (p,F) in R_n. Its ordinary basis can be obtained by integer normal forms of the generators p*X^i and F*X^i reduced modulo X^n+1. This has polynomial bit complexity in n and log p; no factorization of an input ideal or supplied short generator is used. The auxiliary example construction is not an algorithmic reduction from an established hard problem.
