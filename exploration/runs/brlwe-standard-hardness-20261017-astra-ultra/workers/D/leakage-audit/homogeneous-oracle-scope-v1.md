# Oracle scope of D-R1-H

2026-10-17. PROVISIONAL scope clarification prompted by A; does not alter the frozen theorem bytes.

The standalone short-map obstruction in homogeneous-short-map-obstruction-v1.md concerns a public polynomial-time relation procedure using the multipliers and its own local coins. If instead K is computed with calls to the assumed binary-secret recovery algorithm, the same endpoint calculation can be constructive: it directly turns that algorithm into an ordinary-RLWE distinguisher via K b'=K e'. This would be a desired reduction, not a contradiction to its purpose.

Such a construction must show that every recovery-oracle invocation has the exact original binary-secret target distribution, or a rigorously bounded allowed comparison, with the specified independent coefficient errors, uniform multipliers and shared binary secret. A relation oracle on arbitrary chosen instances is not supplied by an average-case binary-recovery hypothesis. The oracle's answers and any response-dependent selection also require rechecking the input-error independence used in the box bound; an oracle procedure that uses only multiplier-derived, independently generated target queries can preserve it, while one that consults the input responses need not.

Thus the finite endpoint formula supplies a precise potential oracle-programming objective. No implementation of that objective has been found here. Source and original binary-target foundations remain OPEN.
