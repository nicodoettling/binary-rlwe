# Nonmaximal-order follow-up after the fractional Gaussian construction

PROVISIONAL coordinator calculation, 2026-10-17. This records a tempting extension and its first exact obstruction, so it is not repeatedly rediscovered. It does not reject all Order-LWE routes.

For an arbitrary integer lattice I with mR subset I subset R, the order O=Z+mR stabilizes I: integers preserve I, and mR times I lies in mR. Thus an arbitrary lattice can be made an O-ideal. This observation alone does not extend the accepted A-FRAC theorem or the proposed multiplicative OHCP map.

First, the fractional ring multipliers that make the old completion integral are `(R:I)={a:aI subset R}`. This is always an R-module, and equals `(R:RI)`, so it remembers only the R-ideal generated by I. For example I=O contains1, hence `(R:I)=R` regardless of m. The corresponding fractional source is the same easy ring-lattice source for all these orders. It cannot retain the missing arbitrary-lattice geometry merely by renaming I an ideal.

Second, the decoding identity requires each sampled multiplier r to stabilize the target lattice. Restricting r to O restores that algebra, but a coefficient basis of O is `(1,mX,...,mX^(n-1))`. A smoothing/sampling lower bound now carries the conductor scale m; it is not the public orthogonal R sampler with width independent of m. Any resulting BDD radius and DGS approximation must pay this factor. No useful compatible reduction is claimed from this observation.

Third, an isomorphism O/qO to R/qR when gcd(m,q)=1 changes the coefficient secret and errors. A binary secret in the displayed O basis is `s0+m sum_(i>0) si X^i`, not the desired coefficient-binary R secret. Dividing by m leaves a special constant coordinate; treating the remaining error as an unchanged product Gaussian is invalid. Any proposed one-bit guess or noise completion must compute both endpoints and charge this anisotropy.

That report remains provisional and is not replaced by this note. I checked that scope in the primary text. No theorem from that paper is imported into this run.

Next discriminating test, if revisited: exhibit a representation map retaining arbitrary I, exact ordinary coefficient-binary target law and a conductor cost below the elementary available-vector bound. Without all three, this is a change of notation or a different computational premise.
