# Scalar padding, exact colon and binary collisions, v2

PROVISIONAL local calculation, 2026-10-17. No theorem acceptance or computational impossibility is claimed. This narrows and repairs the primal part of first-test-v1.md; see primal-response-lattice-gap-before-v2.md. The dual-order calculation in v1 is separate. All latent variables are independent of the fresh binary secret.

Let R=Z[X]/(X^N+1), N a power of two, and let L be a full-rank integral coefficient lattice. Suppose the R-ideal generated by L is R; one sufficient condition is that L contain a monomial. For the order interpretation, take an integer c>=1 with cR contained in L and O_c=Z+cR. Let t>0 be rational. The mask G may have ANY law supported on tL. Fix the constant secret bit S_0 and let the other bits be independent and uniform. The primal order secret is S_O=S_0+c sum_(i>=1) S_i X^i.

The coefficient-integral completion interface requires aG in R for every G in tL, rather than merely aG in the coefficient dual of O_c. Its allowed multiplier module is therefore

    (R:tL)=t^-1 (R:L)=t^-1 (RL)^-1=t^-1 R.

The equality (R:L)=(R:RL) holds because R-integrality of ax for all x in L implies R-integrality of a times every R-linear combination of L. The hypothesis RL=R then gives the last equality. This is an exact algebraic identity, not a comparison of covariance matrices.

For the correct guessed constant bit, the public transport from b=a S_O+E to a coefficient-binary secret is

    A=c a,    B=b+(c-1)a S_0=A S_R+E.

Consequently A lies in (c/t)R. The two guessed branches are correlated; the correct branch is an analysis choice and does not come with a conditioned recovery-success guarantee. The formula presumes that all reductions modulo q and response encodings are executable; a denominator prime to q suffices for the displayed rational identification. If an extra dual-order response scaling is needed, that scale must be applied to both the public multiplier and the error. It is not omitted here by silently changing response lattices.

Now consider two distinct binary secrets with the same fixed S_0. Their difference is c z, where z is a nonzero coefficient vector in {-1,0,1}^N with z_0=0. The supports of G+S_O for these secrets can intersect only if c z belongs to tL. In that case (c/t)z belongs to L, hence belongs to Z^N. Some coordinate of z is plus or minus one, so necessarily

    c/t is an integer.

Thus if c/t is not an integer, all these translated supports are disjoint. Revealing G+S_O and S_0 then determines every secret bit information-theoretically, regardless of the Gaussian width or any correlations in G. The best posterior guessing probability is exactly one. This defeats the intended proof-only ambiguity argument; it is not an efficient attack on the original RLWE target because that proof-only exposure is not public.

If any two such supports can overlap, c/t is an integer, and the transported multiplier lattice (c/t)R is coefficient-integral. It contains no hidden fractional denominator. Integrality alone is not a computational attack: a short-width bound is additionally needed. With q coprime to the nonzero integer c/t, uniform points of ((c/t)R)/q((c/t)R) map exactly to uniform R/qR. For a planted Gaussian on that scalar lattice, a coefficient-size test distinguishes it from this comparator whenever its transported width is sufficiently below q. Increasing the width enough to hide that test has to be paid for in the binary-error completion; no claim about the resulting large-width regime is made here.

Exact two-dimensional controls require no machine enumeration. Take R=Z[i], L=2Z+iZ, c=2, and fix S_0. The two remaining secrets differ by2i. Since L contains the unit i, RL=R.

| t | c/t | Do translates by0 and2i overlap? | Transported multiplier module |
|---|---:|---|---|
| 1 | 2 | Yes,2i belongs to L | 2R |
| 2 | 1 | Yes,2i belongs to2L | R |
| 4 | 1/2 | No, imaginary coefficients of4L are multiples of4 | (1/2)R |
| 2/3 | 3 | Yes,2i belongs to(2/3)L | 3R |

These cases test both directions of the necessary-condition dichotomy, including a rational mask scale. The converse is not asserted for arbitrary L: c/t integral need not make any binary difference belong to L. Zero-mass branches of G can remove overlaps; they cannot create an intersection between disjoint lattice cosets.

The separate coefficient-dual control is also exact. For the same L, L^dagger=(1/2)Z+iZ and O_2^dagger=Z+(i/2)Z. The element a=1/2 pairs L into O_2^dagger, but with G=i/2 in L/2 gives aG=i/4 outside O_2^dagger. Requiring aL contained in2O_2^dagger is equivalent to a in2L^dagger=Z+2iZ, again integral. A dual pairing cannot be substituted for an R-valued pairing without this check.

Reduction-direction disposition: no hardness edge has been obtained. The current candidate maps a hidden-denominator source into a binary target only under an integrality/completion condition. The source comparator is exact uniform in the scalar-coprime case; the planted source loses its denominator whenever the specified mask exposure can hide a nonconstant bit. If the padded lattice has RL different from R, its surviving source module is (RL)^-1 and the original ideal-family problem reappears. A genuinely different pairing or source would require a new full joint-law calculation.
