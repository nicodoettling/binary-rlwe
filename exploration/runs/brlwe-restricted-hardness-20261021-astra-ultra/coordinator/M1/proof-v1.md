# M1 proof, v1 — provisional

## Full-law basis sampler

Let b_i* be Gram–Schmidt vectors. Starting with residual center c=0, for i=n,...,1 set z_i's center c_i=<c,b_i*>/||b_i*||² and width t_i=s/||b_i*||. Draw z_i from D_(Z,t_i,c_i), update c<-c-z_i b_i, and finally output sum_i z_i b_i. The map from integer coefficient tuples to lattice points is bijective. Orthogonal decomposition makes the product of all Gaussian numerators exactly rho_s(x). Every scalar denominator is Z_i(c_i)=sum_z exp(-pi(z-c_i)²/t_i²); it depends on the full preceding choices and is never assumed independent or constant.

Poisson summation gives |Z_i(c_i)/t_i-1|<=2sum_{l>=1}exp(-pi t_i² l²). For t_i>=u>=1 this is at most 4exp(-pi u²), using l²>=1+3(l-1) and the geometric sum (e^(-3pi)<1/2). Put eps=eta/(32n). Each normalizer lies within t_i(1±eps), uniformly in every real center. Consequently the probability ratio between this sequential law Q and normalized D_(J,s) lies between R^-1 and R, R=((1+eps)/(1-eps))^n: integrate the same pointwise numerator/normalizer inequalities to obtain the actual lattice normalizer. Thus TV(Q,D)<=R-1. Since eps<=1/256, log R<=3n eps=3eta/32 and e^(3eta/32)-1<=eta/8 (eta<=1/4). This is a full-history density calculation, not a product of marginal event probabilities.

## Explicit bounded one-dimensional implementation

Here is one conservative finite sampler ensuring conditional TV<=eta/(2n), uniformly for rational centers and squared widths t²>=1. The arithmetic quantities below are recomputed at each call; scalar center reduction preserves integer translation exactly. Let K=ceil(log2(100n/eta))+10, T=1000K², b=ceil(log2(100nT/eta))+10. These ceilings are computed by integer comparisons, using the rational input eta. Reduce c to c0 in[0,1) and an integer offset. Set R=ceil(Kt), using rational squared comparisons, and propose uniform integers in [-R,R+1]. Draw the proposal by bit rejection with at most b attempts, using a fixed failure symbol if all fail. Use b fair bits to accept with an approximated dyadic probability within2^(-b) of exp(-pi(z-c0)²/t²). A certified interval for that exponential of width<=2^(-b-2) determines a dyadic probability within2^(-b); no exact boundary comparison is required. Stop after T proposals; if none accept, scalar fallback is0 (then continue the basis algorithm, or globally fallbackzero).

The ideal proposal range has length N=2R+2<=(2K+4)t. At least t integers satisfy |z-c0|<=t; all are in the range and each has weight>=e^-pi>1/24. Thus exact per-trial acceptance is >=1/(144K), in particular >=1/(200K). Truncating the geometric number of trials at T changes the ideal truncated Gaussian by at most e^(-T/(200K))=e^(-5K). Its removed Gaussian mass is <=4 exp(-pi(K-1)²): bound each tail by its first term plus the Gaussian tail integral and use Z(t,c)>=t(1-4e^-pi)>t/2. (The range includes every integer of distance <Kt from c0.) The dyadic-coin discrepancy is at most T2^-b; proposal-cap discrepancy also at most T2^-b because a fresh uniform b-bit-range proposal succeeds with probability>=1/2 per attempt. Therefore scalar TV is at most

    4e^(-pi(K-1)²)+e^(-5K)+2T2^-b < eta/(2n).

This inequality follows directly from K>=log2(100n/eta)+10 and b>=log2(100nT/eta)+10; no tail is deleted and renormalized without being charged. Approximate acceptance probabilities may increase or decrease exact weights; the per-trial coupling handles either. All exponents queried have magnitude O(K²), so certified pi/exponential evaluations require polynomial bit complexity in K,b and input bit lengths. Taylor/range-reduction evaluation provides such fixed routines. Uniform proposals use O(log R) bits rather than enumerating the range; R may have exponential numerical value.

Each subsequent scalar center depends on represented previous outputs. The bounded proposal range yields |z_i-c_i|<=R_i+2 on nonfailure branches; fallback0 is also bounded by a rationally computable quantity involving c_i. Repeated rational additions/products and exact Gram–Schmidt on n represented vectors cause polynomial bit growth, since there are n stages and each coefficient update has input-sized rational multipliers and O(log R_i) extra bits. One may precompute a conservative polynomial operand bound by this recurrence and tag any malformed input; a finite valid-input algorithm is all-input bounded after verifying dimensions/nonzero determinant and the scalar size promises. A hybrid over complete histories adds <=eta/2 total scalar error, so total TV is <eta. Each output is a lattice point, including all fallback branches. The implementation uses fair bits and ordinary bounded integer/rational arithmetic; no ideal sampler or short-basis advice is hidden.

## HNF and exponent criterion

Use column HNF in upper-triangular convention (reverse row and column ordering if an implementation returns the lower convention; row reversal is an orthogonal coordinate permutation and is undone). Column j lies in span(e_1,...,e_j), so Gram–Schmidt vector j equals H_jj e_j. The lattice flag J intersect span(e_1,...,e_j) is generated by its first j columns. Since e e_j belongs to this flag, its last coordinate is an integral multiple of H_jj. Therefore H_jj divides e. The largest Smith invariant is the exponent of Z^n/J, hence the smallest such e. Hermite/Smith form with unimodular multipliers can be computed in polynomial bit complexity for nonsingular integer matrices; primary source Kannan–Bachem1979, DOI10.1137/0208040. The publisher abstract explicitly specifies polynomial intermediate bit sizes; this import is only integer normal-form computation, not a short-basis algorithm. Current source-access details are recorded separately.

## Effective collision basis

Because there are D cosets and at least D+1 binary vectors in h0 coordinates, two have equal residue. Their difference f is nonzero ternary and has norm<=sqrt(h0). Since R's fraction algebra is a field, the n rotations of nonzero f are rationally independent. Let V be their matrix; each column has norm||f||. In V coordinates, M=V^-1 J is a rational lattice containing Z^n, since all rotation columns belong to J. Clear denominators by a positive integer d so dM is integral. Compute its upper column HNF H; U=H/d is a basis of M. The flag argument from the previous paragraph, now using e_j in M, shows 0<U_jj<=1. Columns of VU have the same successive rational spans as columns of V, so their Gram–Schmidt vectors are U_jj v_j*. Thus their lengths are <=||v_j||=||f||. All matrices and denominators have polynomial bits in the original basis and f by determinant bounds and normal-form algorithms. There is no exponentially large-coordinate search in this postprocessing. Only the D+1 collision enumeration is charged as numerical D runtime.

## Delivered-width application and adaptive scope

For eta=2^-4n, u=4n, 4e^-16pi n²<=2^-4n/(32n) for n>=2. The same-J equations give

    W>=256sqrt(2)n^5 k chi ceil(sqrt(kn))ell²/delta,

using q>=8n³ceil(sqrt(kn))ell⁴. In particular W>4n sqrt(n), and h0<=n in the eligible family. The polynomial-index simulation therefore applies at the exact delivered width, with no replacement modulus or changed recovery premise. Small HNF diagonal is a separate criterion that can hold at exponential index.

For n>=4, putting y=X^(n/4), (y²+y-1)(y²-y-1)=y⁴-3y²+1. Modulo3 this is X^n+1. Thus R/(3,g) is F3[X]/(g), dimension n/2 and cardinal3^(n/2). Its additive exponent is3. Since3^5=243<256=2^8, its norm is below2^(4n/5). Any odd prime q=1 mod2n has q!=3. The width lower bound exceeds12n. No primality of g is used.

For adaptive classical calls, couple the complete ideal and implemented history until the first discrepancy; at each identical history use a coupling of the next full conditional law. Conditional disagreement is <=eta_j, so the union/expectation bound gives sum eta_j for bounded L. At histories already different, no comparison is needed. Adaptive selected support, zeros and failures are part of the history. Comparing to an imperfect oracle uses the triangle inequality at the same conditional histories, giving eta_j+alpha_j. This argument does not claim that marginal bounds imply conditional bounds, nor that a classical simulator replaces coherent oracle gates. CP-1 must still reject the old product claim; this proof only uses conditional additive hybrid losses.
