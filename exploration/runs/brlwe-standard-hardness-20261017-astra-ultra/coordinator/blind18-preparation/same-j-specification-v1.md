# Finite specification of the same-ideal sampler

Use the parameters and four mathematical interfaces in the two companion files. This specification defines the composition; the exact two long finite subroutine specifications are bound by SHA256 in interface-statements-v1.md.

1. Compute the ordinary rational inverse-ideal basis and \(B\) for \(qJ^{-1}\), its HNF/SNF representatives, and all scalar parameters. Verify the integer/rational input conditions; the real numerical inequalities are supplied mathematical promises. Their certified sufficient checks may use strict slack. All target and lattice arithmetic is rational; no rounded target near the BDD boundary is substituted.
2. Fix the bounded test \(A_J\). For each of its \(k\) finite \(F\) inputs, apply interface II's exact B-v2 scalar kernel and capped uniform quotient draws. Identify its result in \(R/qR\) by \(v/D\mapsto vD^{-1}\bmod q\). Choose \(n\) independent fair secret bits. Independently sample the \(kn\) coefficient errors using that same scalar kernel with width \(\sigma\), center zero, tolerance \(\nu\), and the complete-wrapper elementary cap. Construct the ring samples, invoke the supplied recovery code, and test equality with the actual secret. Every invocation starts with fresh coins. This definition applies to every valid \(F\) tuple, regardless of how a calling algorithm produced it.
3. Fix the C8 bit program of interface III with this exact \(A_J\). All comparisons use its bounded two-orientation loops, the single global sample counter, prescribed certified evaluations, and rational final candidate verifier. An arbitrary wrong orientation or target outside the BDD promise changes correctness only; it never removes the time bound.
4. Calculate \(H,N_g,C_u,b_u,m\), all quantum precisions, and all caps from the theorem. Construct \(Q_*\) recovery call slots. In each slot a bounded dispatcher simulates the C8 program until its next recovery invocation or termination, freezes the machine state, and exposes one valid input. A terminated/inactive branch exposes a fixed valid dummy input and ignores the answer. Execute one actual recovery-code block with fresh coins, route its answer back, and continue. After slot \(Q_*\), simulate the remaining nonrecovery work to termination. Each simulation segment uses a supplied all-input cap; all work and dummy computations are retained. The resulting actual circuit has \(Q_*\) recovery blocks per forward execution. Count its gates and coin bits after adding exact membership/conversion and the modular output \(v-HB^{-1}\lambda\).
5. Run the finite quantum sampler of interface IV using this actual circuit. For precision evaluation use its fixed rational Machin/Taylor loops \(L_{\rm eval}=J_{\rm eval}=2^{16}A_{\rm eval}^4\); no arbitrary rotation is a primitive. Its scalar Gaussian preparation uses initial support \([-N_g,N_g-1]\), dyadic amplitude precision \(p_g\), cap \(R_g\), and output zero on exhausting a cap. Compute \(u=\lfloor A^{-1}x\rfloor\) and \(y=x-Au\); measure and retain the actual \(y\). Compute \(v=u\bmod H\). Use a uniform superposition of all decoder random bits, reversibly evaluate the full circuit, XOR its output into \(u\), and reverse it, including all work registers. This is one logical clean call, with one forward and one inverse execution.
6. Perform the tensor-product \(H\)-point Fourier transform with the dyadic-phase resource routine fixed in interface IV: known angles, resource precision \(p_{\rm ph}\), at most \(M_{\rm ph}\) resources, each at most \(R_{\rm ph}\) preparation attempts, and bounded adaptive correction. Exhausted caps output zero. Measure the Fourier label, center it coordinatewise in \([-H/2,H/2)\), and output \(B^{-T}t_{\rm cent}\in\Gamma\).
7. Multiply the resulting rational lattice point by \(q\) and conjugate. Its coefficient coordinates are integers in \(J\). Output that point classically. All failure branches also output the zero of \(J\).

The finite GP input group \(F=(DP)^{-1}\mathbb Z^n/qJ^{-1}\) and the quantum target grid \(L/H\) are different objects. The former defines the fixed test's distinguishing experiment; the latter supplies finitely encoded rational BDD targets. The reduction is given no external sample oracle for either law.

For host compilation use any explicit finite bit-machine unrolling that retains the \(Q_*\) call-slot layout. The execution count in the theorem uses the emitted Boolean circuit, while the host's compilation/serialization cost is charged separately as a polynomial in the finite description and unrolling bounds. Each recovery execution is a coherent use of supplied code with its internal fresh coins retained until reversed; it is not a call to a classical remote service.
