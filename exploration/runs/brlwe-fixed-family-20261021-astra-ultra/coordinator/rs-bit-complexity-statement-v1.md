# SV-RS-BIT-v1: bounded randomized binary-p implementation

Use the ordinary-basis source promises and rational target/radius inputs of SV-RS-DECODE-v2, SV-GAP-DECODE-v1, or SV-LIST-DECODE-v1, with n>=2 a power of two and additive quotient exponent a completely split odd PRIME p. Let 0<eta<1 be a supplied rational failure tolerance. There is a bounded randomized algorithm which returns the correct promised lambda with probability at least1-eta, and otherwise returns FAIL. Its runtime is polynomial in n, log p, log(1/eta), and complete input lengths; for LIST also charge NUMERIC d and B. It uses no factorization, supplied primitive root, short basis, or source Gaussian oracle. The same source radius and all the corresponding decoder guards remain unchanged.

The algorithm computes p as the additive quotient exponent from the ordinary basis. Put m=ceil(log2 p), a_int=ceil(log2(1/eta)) and L=8*a_int. On each of L fresh trials draw m independent fair bits forming b in[0,2^m). If b=0 or b>=p the trial fails. Otherwise form alpha=b^((p-1)/(2n)) mod p and keep it only if alpha^n=-1 mod p. Stop on the first success, or return FAIL after L failures. All trial randomness is fresh conditional on the complete previous history. The algorithm may then enumerate the n primitive roots as alpha^j for odd1<=j<2n and use the basis-recognition, Fourier/GRS decoding, and exact rational lifting procedures of the cited source statements, replacing their scans through F_p by the acquired root and these n roots.

For RS and GAP no other scan over every field element is needed. For LIST, its polynomial-root coefficient recursion must ALSO replace each full-F_p root scan by an explicitly charged finite-field polynomial-root algorithm; the present claim does not make that replacement. Therefore the binary-p runtime conclusion applies to RS and GAP only. LIST retains its earlier numeric-p cost, except that primitive-root acquisition alone has the displayed faster implementation.

The prime and complete-splitting hypotheses are promises. No deterministic polynomial-bit factorization or primality recognition on arbitrary composite inputs is asserted. The guarded decoder can return FAIL on unpromised inputs; all loops remain bounded by the stated finite code schedule. An effective prime-family generator is a separate construction cost, not supplied by this lemma. At the inherited inverse-polynomial radius, the RS/GAP guards themselves already bound p polynomially in value, so this implementation improvement is not a new hardness connection or an additional asymptotic inherited-radius family.
