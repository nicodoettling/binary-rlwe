## What survives the adversarial checks

1. **Sampler coins versus the precursor.** The posterior equality follows from Bayes' rule with the unchanged prior and the entire conditional joint likelihood. The hypothesis is essential. A new exact-Gaussian-marginal control in [the support note](C02/checks-and-regressions.md) takes E_1=Z and E_2=(-1)^{S xor T}Z: every error separately has the correct discrete Gaussian law even conditional on S,T, yet revealing T raises scalar guessing from 1/2 to 1-W_{sigma,q}(0)/2. The errors are correlated, so this control violates the reference product law and is correctly excluded by C02. Its purpose is to prevent a future Gaussian decomposition from checking only marginals.

2. **No-wrap decoder and data processing.** From uF=S+G+q(SK-kF), centered reduction recovers S+G on the stated event, and -qJ is the correct secret coset. The tail includes the whole noisy expression. F's modular inverse on integer vectors does not make multiplication by F invertible on a real torus. The continuous transcript is a postprocessing of the precursor with sampler coins, so precursor recoverability does not imply a public attack. The fixed-A discrete E04 example is consistent with this distinction; its numerical zero entropies are explicitly approximate.

3. **Occupied-coset entropy and injection.** Each occupied Boolean fiber contributes exactly 2^{-n} to average guessing, giving n-log2 N_occ regardless of unequal fiber sizes. The unwrapped integer augmentation permits the stated leakage charge; a modular support argument does not. Both strict injection certificates are correct. The boundary n=2, f=1+X has sigma_min=sqrt(n), norm n^{n/2}, and a Boolean collision, so replacing either strict inequality by a non-strict one would be false.

4. **Public source tuple.** I checked the source definitions and Section 6 sampler in the supplied primary BD2020 text, then reconstructed the hybrid. The DSPR simulator needs only the ratio challenge h; an HNF challenge (h,b) replaces one output while the other outputs use fresh local source secrets and errors with the same public h. This proves joint tuple pseudorandomness conditional on the stated source assumptions, with one DSPR term and m HNF terms. Uniform marginals alone would fail: A_1=A_2 uniform is efficiently distinguished from an independent uniform pair. No independent hardness support is supplied for a new Boolean-lossy denominator law.

5. **Denominator tests and Lucas algebra.** The low-exponent test is valid under the coprimality, short-ratio, and no-wrap conditions, including polynomial exponent enumeration. The Lucas identity T^n+I=L_{n/2}T^{n/2} proves the stated quotient, exponential exponent, and index entropy bound. The bound ||M_f||<=sqrt(5) is correct. Exponential exponent evades the one scalar-exponent test, but the fixed known f still permits the short-numerator test. Neither low index nor many Boolean collisions establishes pseudorandomness.

One wording qualification should remain explicit whenever these tests are called attacks: the displayed false-positive bound must be below the structured acceptance probability. The inequality kappa L<q/2 alone only establishes no-wrap correctness; if (q-1)/2<=kappa L<q/2, every uniform input passes. The dossier's intended polynomial gap for the constant-exponent example avoids this boundary.

## Strongest missing step and quantifier boundary

For some independently supported, efficiently sampled **joint** public law X and a fixed polynomial ring sample count m, the missing statement is

    Pr_{a~X}[g_{sigma,q}(a) <= 2^{-h(n)}] >= delta(n),
    h=omega(log n),  delta>=1/poly(n),

under precisely the independent coefficient-binary secret and fixed iid coefficient discrete-Gaussian errors in `target.md`, with any smoothing loss negligible. Source canonical width gamma, denominator coefficient width kappa=gamma/sqrt(n), continuous masking width t, and target discrete width sigma are different parameters. None of the checked controls proves this bound for the same X whose public pseudorandomness is justified.

Even if this missing bound were proved, its immediate cited consequence is mild search hardness. A half-lossy noiseless public-matrix family in the support note has average recovery probability at least 1/2 while satisfying the corresponding mild notion; thus sometimes lossiness alone cannot be promoted to negligible average success. The stronger sufficient bound E_X g<=negl would imply standard search hardness at the same fixed m through the dossier's valid public testing reduction, but is also unproved. One-sample controls do not justify arbitrary polynomial m, and subset-sum rerandomization does not preserve the exact reference error law. Decision hardness remains separate.
