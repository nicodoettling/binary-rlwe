# Bounded research assignment

The coordinator must paste the COMPLETE RESEARCH_SCOPE.md text here before sending the assignment. A link alone is insufficient. Preserve this scope in any checkpoint used to reconstruct the task.

Supply: assignment ID; role; exact mathematical question; frozen claim version and assumptions; absolute run and output paths; permitted inputs; permitted primary sources; task UTC deadline; run UTC hard deadline; experiment allocation; and expected deliverable. Every worker uses Astra ultra, spawns no agents, and creates no goal or background continuation.

Ordinary workers read the assigned source contract, complete relevant historical counterexamples and prior notes. A designated blind reviewer instead receives only the research scope, frozen theorem/definitions/assumptions, boundary examples, permitted sources and this role's instructions. Do not send that reviewer the plan's scientific assessment, proposed proof, claim status or suspected error. Freeze its report before revealing previous work.

Deliver a note containing the exact joint distribution, public/hidden information and conditioning; claim and quantifier order; complete public reduction or candidate algorithm; one shared parameter regime with all error/resource terms; evidence and source hypotheses; strongest objection; and exact unresolved obligation. A computational assumption requires an explicit experiment, not a name. A novel premise tailored to the target remains a new hypothesis even if it contains no syntactically binary secret.

For reductions, state both challenge worlds and what the simulator computes without hidden J,U,F,H. For noise, preserve the distinction between observable correctness and stronger retained-variable conditions; revise the full hybrid for any relaxation. For multiple samples, specify the common K, all auxiliary observations and the full joint noise law. State whether an algorithm is polynomial, subexponential or information-theoretic. Small numerical examples do not establish asymptotic hardness.

For reviews, identify exact claim versions and input hashes. Seek the most consequential false statement or omitted assumption. Preserve exact counterexamples and bound the scope of negative results. A nonauthor recheck of a repaired statement must explicitly revisit all relevant old controls and at least one control targeted at the repair. No positive or negative verdict quota applies.

Write a partial note every five minutes when execution permits and before long tool calls. On each result send the coordinator the note path, changed claim IDs, objections, and next step so it can reconcile immediately. Reserve the last five minutes for writing. Experiments require coordinator allocation and enforced timeout, at most 300 seconds and never past the task deadline. Stop by the deadline and retain incomplete calculations.
