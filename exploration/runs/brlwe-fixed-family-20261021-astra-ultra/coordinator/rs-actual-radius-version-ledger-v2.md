# Additional effective-parameter correction

SV-RS-ACTUAL-v2 is preserved. Independent statement reconstruction of v1 identified that an arbitrary fixed real rho does not itself supply an effective exact floor computation for the constructed t. The dense-family dependency already takes rational rho. Version3 explicitly makes rho a fixed rational constant in (0,1). No v1/v2 acceptance is claimed. A family for a larger arbitrary real norm bound can instead choose a fixed rational rho0 below it, but this extension is not needed for the v3 claim.
