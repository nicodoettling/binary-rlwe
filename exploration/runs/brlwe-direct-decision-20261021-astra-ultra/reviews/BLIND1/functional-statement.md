# Selected-functional full-observation statement

Let J be a full-rank sublattice of Z^n, S uniform on {0,1}^n, G independent D_(J,t), and Y=S+G. Let F_1,...,F_m be fixed deterministic finite-valued functions on the cube. A predictor observes Y and chooses ONE pair (j,v), succeeding if F_j(S)=v. Define N(c,j,v)=#{b in cube:b modJ=c,F_j(b)=v} and K=2^(-n) sum_c max_(j,v)N(c,j,v). Then for all r0>0,

K <= p_selected <= min(1,K exp(pi n/(4r0))(1+r0/t^2)^(n/2)).

Metadata is allowed only if conditional on each revealed value the original independent product law of S,G survives (or the corresponding regular conditional law in a non-atomic model). For t=2n^2 ell, r0=t the overhead is at most exp((pi/8+1/4)/(n ell)). The selected root application sets F_j(b)=b(zeta_j) modulo q. This is a statement to assess as part of the main theorem, not a supplied assumption of correctness.
