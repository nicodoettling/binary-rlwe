# Direct-oracle and one-sample hybrid alternatives, 2026-10-21

Exploratory interface audit, not an impossibility theorem or an accepted reduction.

The exact target fixes q(n), sigma(n), one uniform binary S, independent uniform A_i and independent coefficient discrete errors before all polynomial k and inverse advantages. Feeding a distinguisher fractional-source public multipliers instead does not meet its promised public law. Its all-input execution bound covers runtime on that input; it does not promise a useful acceptance gap there.

A direct whitening attempt is to draw U uniform, put A'=A+U and B'=AS+E+US. The wrapper knows S, so the arithmetic is executable. Conditional on every incoming A, A' is uniform and B'=A'S+E. This produces the exact target in both incoming source worlds. It therefore erases the needed source gap. Keeping part of A requires a new comparison theorem rather than this equality.

A one-influential-sample hybrid may replace k-1 slots with synthetic target samples generated with the wrapper's known S. The resulting oracle call does preserve the common S. However, those synthetic responses depend on S and become auxiliary information to any selected-root or whole-secret predictor built from this wrapper. The historical fractional-source guessing bound does not give a bound with this S-dependent advice. Generating the other slots with independent secrets avoids that advice only by changing the full target batch law. Independent execution coins do not fix either issue.

A single-query or randomized selected-root estimator could improve calibration losses in epsilon. It still consumes k genuine samples in each promised call. The existing completion lower floor contains sqrt(K), with K at least k, so reducing calibration exponents alone cannot establish the fixed-family quantifier order. This is a restriction of that composition, not a proof against a new computational reduction.

Useful open interfaces are: a computational source comparison that tolerates the exact S-dependent simulation; a shared-secret synthesis kernel with proved posterior normalization; or a distinguisher-to-functional reduction with a different source statistic and an explicit all-input execution schedule. The finite nonlinear kernels in workers/FF3 remain evidence for the second possibility, not for a blanket negative conclusion.
