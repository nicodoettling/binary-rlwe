The coordinator fills every field, appends the complete RESEARCH_SCOPE.md verbatim, and saves the actual assignment in the new run's worker directory.

- Run service start, wrap-up, graceful-shutdown and final cap UTC timestamps:
- Parent coordinator; no worker-created agents, goals, services, remote jobs, commits, or external messages.

Save a useful partial result before a long tool and at least every five minutes. Name the exact obstruction or new lemma; do not send only a task-completion status. Preserve code, original outputs, finite witnesses, precision/tail qualifications, and negative results. Record late checkpoints and ordinary tool/source-access errors honestly.

For **blind review**, create a fresh thread with `fork_turns="none"` and omit candidate proof, prior status, coordinator narrative, suspected failure, and the general repository reading list. Supply only frozen definitions/theorem, explicit assumptions, permitted sources, and neutral boundary examples. Freeze the complete report before receiving prior objections and code. The coordinator imports all historical regressions; after the blind phase, the reviewer can test them against the revealed candidate.

For **full review or repair recheck**, identify exact proof file/version/hash, each load-bearing dependency, all old counterexamples, and one new targeted finite-model search. A change invalidates downstream status. Return claim-addressed dispositions and complete reasoning; a confidence score or agreement count is not evidence.

At the assigned deadline, stop new work and return a durable report identifying what is proved, refuted, provisional, or open. This worker's completion does not imply the coordinator goal is achieved. Any remaining experiment must be canceled within the shared cap.
