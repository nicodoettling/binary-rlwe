# Integer-error residue test for a modified proof mask

PROVISIONAL exact algebraic/finite test, not a general obstruction or a new hardness theorem. The new ingredient tested here is allowing the proof mask G outside the ideal, including a continuous G, to avoid the integral binary-collision restriction. The target and source laws are not changed by this proposed proof modification.

Fix the complete unwrapped source state (J,a_1,...,a_k), with integral J and a_i in J^-1, before the independent coefficient-binary S. Public A_i is the natural modq reduction; source endpoints remain iid D_(J^-1,s) versus iid uniform R/qR with identical J metadata. The executable wrapper in EACH world still samples independent S and integer coefficient D_sigma errors E_i and outputs(A_i,A_i S+E_i). Under the uniform comparator this is the exact target. No new source-to-standard problem map is asserted.

The attempted planted analysis chooses a real/rational mask G with a broad law, puts Y=S+G, and completes E_i=a_i G+H_i with E_i in R. If G is not supported on a lattice mapped into R, then H_i must live in the shifted support R-a_i G. It cannot be replaced by an independently chosen integer Gaussian. Gaussian marginal/covariance matching would not repair this support defect.

For EVERY realization of this exact completion, regardless of Gaussian shape or independence,

    a_i Y+H_i = a_i S+E_i,
    (a_i Y+H_i) mod R = a_i S mod R.

Thus the usual proof-only exposure of the unwrapped a_i, Y and H_i reveals the full residue vector(a_i S modR)_i. Put

    J_a={z in R: a_i z in R for all i}.

This is an integral ideal containing J, and the displayed residue map on binary S has kernel differences exactly J_a. If the binary quotient map modulo J_a is injective, the exposed information determines S exactly, almost surely. In particular, if the fractional ideal generated by the a_i is J^-1, then J_a=J, by ideal inversion. The last condition is an explicit condition on the source state, not an assertion about the probability that iid Gaussian samples generate the inverse ideal. Zero-mass conditional observations carry no asserted posterior.

For continuous G and nonzero a_i, its image modulo R is non-atomic when G has a density, whereas independent integer H_i would require a_i G in R. That event has probability zero because the inverse image is a full-rank discrete lattice. Choosing the necessary shifted H_i can make an integer error, but revealing H_i restores the exact residue information above. This is a full-joint-law issue, not a discrepancy in covariance.

The proposed proof therefore fails at a precise interface: it cannot simultaneously use a freely continuous mask, independent integer completion noise, and the original exact integer target errors. Allowing shifted dependent H_i preserves the target support but defeats the intended guessing bound whenever J_a is binary-injective. This does NOT prove that the actual public transcript reveals those residues: unwrapped source state and H_i remain proof-only. A new analysis that does not expose H_i, a different target/source law with a proved comparator, or a computational simulation remains outside this test.
