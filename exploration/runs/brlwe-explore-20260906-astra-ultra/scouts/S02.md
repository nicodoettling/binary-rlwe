# S02 — Prior change as a secret-preserving channel

**Fully written small calculation.** Define the source independently: \(U\) is uniform on \(R_q\), and \(X=(A_i,B_i=A_iU+E_i)_{i=1}^m\), with independent uniform ring multipliers and the reference coefficient Gaussian errors. Only the source secret prior differs from the reference. Let \(C=\{0,1\}^n\). A meaningful ideal comparison family \(Q_u\) chooses \(V\leftarrow C\), sets \(R=V-u\), and generates a reference transcript \(Y\) with secret \(V\). The simulator outputs \((R,Y)\); binary recovery then gives \(u=V-R\). Merely generating the marginal distribution of \(Y\) is vacuous: discard the input and sample it afresh.

**Source-verified result; own application.** Statistical deficiency uses parameter-independent kernels:
\[
\delta(P,Q)=\inf_K\sup_u\operatorname{TV}(KP_u,Q_u).
\]
An exact kernel gives the Blackwell comparison. Deficiency controls bounded decision risks; it does not impose efficient computation. See Ray–Schmidt-Hieber, [Appendix E, manuscript p.52; §6, Eq. (6.1)](https://arxiv.org/pdf/1608.01824). For average-case hardness, a sufficient obligation is one uniform polynomial-time kernel satisfying
\[
\operatorname{TV}\bigl(\mathsf{Law}(U,K(X)),\mathsf{Law}(U,R,Y)\bigr)\leq\varepsilon(n)
\]
for negligible \(\varepsilon\). A binary solver then transfers with at most \(\varepsilon\) success loss. This is the missing implication to independently established source hardness; no hardness is assumed throughout the broad reference parameter region.

**Mechanism 1 — fully written small calculation; natural candidate refuted.** Choose a known unit \(t\) and shift \(r\), independently of the source transcript, and set
\[
A_i'=A_it^{-1},\qquad B_i'=B_i+A_i'r,\qquad V=tU+r.
\]
Then \(B_i'=A_i'V+E_i\): rank one, multiplier independence, sample count, basis, modulus, and the complete error law survive. But \(V\) remains uniform on \(R_q\). Binary membership has probability \((2/q)^n\), and testing it requires the unknown secret. Adaptive choices of \(t,r\) demand a new joint-law argument. This refutes this affine candidate, not arbitrary randomized reductions.

**Mechanism 2 — fully written small calculation; efficiency unresolved.** Use the wrapped likelihood
\[
L_u(A,B)=\prod_{i,j}W_{\sigma,q}\bigl((B_i-A_iu)_j\bigr).
\]
Sample \(\widehat U\) with probability \(L_u/\sum_{w\in R_q}L_w\), independently sample \(V\leftarrow C\), and output \(R=V-\widehat U\), \(Y=(A,B+AR)\). The posterior identity gives
\((\widehat U,A,B)\overset d=(U,A,B)\); consequently \(B-A\widehat U\) has exactly the required independent wrapped Gaussian coefficient law. Thus \((V,Y)\) is exactly the reference target joint law, with no extra samples or independent rotations.

The serious objection is that this couples recovery to \(\widehat U\), not the original \(U\). Given \(X\), these are independent posterior draws. Recovery succeeds with
\[
p_{\rm col}=\mathbb E_X\sum_u p(u\mid X)^2,\qquad
p_{\rm guess}^{\,2}\leq p_{\rm col}\leq p_{\rm guess},\qquad
p_{\rm guess}=\mathbb E_X\max_u p(u\mid X).
\]
An efficient posterior sampler already solves source search whenever optimal guessing is high. The target oracle contributes nothing to that step. An exact statistical sampler therefore does not supply an efficient reduction.

**Fully written small calculation — cheap diagnostic, no experiment.** In the explicitly different toy parameters \(n=1,q=3,m=1,\sigma=1\), write \(h=W_{1,3}(1)=W_{1,3}(2)>0\). Optimal source guessing and ideal-\(Q\) guessing differ by \(1/18+h/3\); hence every kernel has average joint error at least that amount. The derivation is in [partial.md](S02/partial.md). This is a finite statistical obstruction, not an asymptotic cryptographic lower bound.

**Source-verified comparison.** Brakerski–Döttling already use randomized postprocessing with a lattice-coset indicator; their binary entropy limitation remains ([§1.2, pp.5–6; Theorem 6.9](https://eprint.iacr.org/2020/1185)). HNF changes the secret to selected source errors and consumes samples ([Boudgoust et al., Theorem 5.1, pp.19–20](https://eprint.iacr.org/2025/1472)); Gaussian source errors therefore do not yield binary secrets by that substitution.

**Unresolved.** Shannon mutual information, optimal guessing, Blackwell/deficiency comparison, and computational indistinguishability are distinct obligations. Matching either scalar information measure does not construct a channel; indistinguishable public marginals do not establish the required secret coupling.
