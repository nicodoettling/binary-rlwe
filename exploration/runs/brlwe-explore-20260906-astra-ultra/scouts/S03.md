# S03 — Coding, shaping, and ring towers

**Outcome: unresolved hardness implications; two direct simulators refuted.** Degree can absorb the binary secret representation exactly. The missing operation is public transcript completion with full-ring uniform multipliers and the correct joint error. Calculations and source checks are in [S03/notes.md](S03/notes.md). No experiments were run.

**1. Pack module rank into extension degree.** Let n,d be powers of two, R_q=Z_q[Y]/(Y^n+1), T_q=Z_q[X]/(X^(nd)+1), and Y=X^d. Packing S=Σ_j X^j s_j(Y) changes degree n→N=nd and rank d→1, retaining q and the coefficient basis: iid binary module coefficients become exactly iid binary target coefficients. Intended sample count is m→m; target errors must remain independent coefficient D_sigma, without an embedding change.

**Fully written small calculation:** for d=2, define

C_r(u,v)=Σ_(j=0)^r u_jv_(r-j)−Σ_(j=r+1)^(n−1)u_jv_(n+r−j),

J_0(u,v)=−C_(n−1)(u,v), and J_r=C_(r−1) for r>0. For A=a_0+Xa_1, every coefficient is

B_(2r)=C_r(a_0,s_0)+J_r(a_1,s_1)+E_(2r),

B_(2r+1)=C_r(a_1,s_0)+C_r(a_0,s_1)+E_(2r+1) mod q.

Given one uniform Module-LWE row (u_0,u_1), setting a_0=u_0 and a_1=Y^(−1)u_1 produces exactly uniform A over **all** T_q. Its response supplies B_even=a_0s_0+Ya_1s_1+e. The missing B_odd needs the correlated row (a_1,a_0), whose response the simulator does not know. Rotating the first response does not supply it. A single-response linear completion cB_even requires ca_0=a_1 and cYa_1=a_0, hence a_0²=Ya_1²: an unsupported restriction on uniform A.

Conversely, normalized trace Tr_(T/R)(B)/2 extracts one exact binary Module-LWE sample per ring sample, preserving q, m, and coefficient width sigma. A module solver recovers both secret blocks, hence S. This proves the **opposite reduction direction** from the one needed to import module hardness.

**Source-verified comparison:** [Peikert–Pepin, Theorem 6.1](https://eprint.iacr.org/2019/878.pdf), gives the extension-to-base-module direction in its native dual-order formulation. [Boudgoust et al., Theorem 2](https://eprint.iacr.org/2021/265.pdf), increases binary target rank at fixed degree. The first substantive new step would be reversing the trace direction by completing correlated responses. That hardness implication is **unresolved**. Cheap next test: demand both coefficient identities from any proposed d=2 simulator, then test its full conditional likelihood ∏_r W_(sigma,q)(B_r−(AS)_r). Covariance alone does not establish that likelihood.

**2. Radix shaping at unchanged modulus.** Define the R_q-linear map Φ(S)=Σ_j 2^j s_j(Y). Independent binary target blocks induce independent source coefficients distributed as uniform integers in [0,2^d−1] modulo q. Their joint distance from uniform R_q is at most nq/(4·2^d), negligible for d≥log_2q+ω(log n). Thus the proposed source has degree n, rank one, q-ary secret; the binary target has degree nd, rank one, unchanged q and intended m. Recovering S recovers Φ(S).

**Fully written small calculation:** Φ(X^d)=Y but Φ(X)^d=2^d. Already for d=2,

Φ(AS)−Φ(A)Φ(S)=(Y−4)a_1s_1.

This secret-dependent defect prevents direct simulation. If Y−4 is a unit, intertwining multiplication forces a_1=0, restricting A to a subring. Imposing Y=2^d instead changes the source to Z_g, g=gcd(q,2^(nd)+1), with only polynomially many scalar secrets when q=poly(N).

**Source-verified comparison:** [Albrecht–Deo, Corollary 3](https://eprint.iacr.org/2017/612.pdf), compresses rank using (1,q,…) while increasing modulus to q^d; its output secret is generally nonbinary. The proposed difference is spending extension degree to retain binary coefficients and q. The missing implication is a public binary-preimage simulator handling the wrap defect and independent Gaussian target noise; no source/target width relation is established. Cheap next test: solve Φ(XS)=aΦ(S) before analyzing noise. The direct equation is **refuted**; broader quotient or nonlinear shaping reductions remain **unresolved**.
