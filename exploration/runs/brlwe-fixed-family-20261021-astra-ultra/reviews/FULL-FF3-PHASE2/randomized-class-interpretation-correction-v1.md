# Persistent hidden class state: correction to this review's preliminary interpretation

Before the root's21:01Z notice, this reviewer read the optional randomized-class clause of FF3-COMPRESSED-SELECTOR-INFORMATION-v1 as sampling the declared R(c|x,e) afresh on every retry. Under that stronger reading, pointwise normalization gives the accepted law mu(e)R(c|x,e)G(e,c), a geometric meanM and the ML/N guessing bound. That preliminary interpretation is preserved here. It is not a valid acceptance of the literal broader wording.

FULL-REPAIR4, a separate reviewer, found the persistent hidden seed counterexample preserved by root in coordinator/selector-randomized-class-rejection-v1.md. Recompute it directly: N8, E uniform8, X=S, class alphabet{0,1}, G=2C,M2. One seed chooses a hit-only class C=1[E=S] with probability4/7, or the constant class C=1 with probability3/7, and persists through all retries. Averaged one-trial normalizer is(4/7)(2/8)+(3/7)2=1 at every x. Conditional on the hit-only seed the acceptance probability is1/8, eventual E=S, and expected trials8. Conditional on the constant seed the first proposal is always accepted and E is uniform. Thus mean trials=(4/7)*8+(3/7)*1=5, not2. Given output E, correct guessing succeeds with probability4/7+(3/7)(1/8)=5/8>ML/N=1/2. The returned class is always1, so it supplies no extra variable needed for this calculation.

For comparison, genuinely fresh per-trial seed draws give success probability1/2 on every fixed-input trial. The accepted probability of E=S is[(1/8)*1]/(1/2)=1/4 and the mean is2. The persistent model changes the accepted distribution because survival reweights the hidden seed. Fresh proposal and acceptance coins alone do not make class states independent across retries. This is exactly a support/normalization issue of the type guarded by CP1; a marginal class law does not determine the retry process.

Disposition: reject the optional randomized-class clause of the frozen v1 as a blanket claim without a fresh-class/fully-conditioned-state hypothesis. The deterministic-class core and its exact Gaussian target corollary remain supported. Public extensions inheriting this optional clause reopen even if their public Z is discrete.
