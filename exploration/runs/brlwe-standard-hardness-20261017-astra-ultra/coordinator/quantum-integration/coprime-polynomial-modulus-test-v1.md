# Coprime polynomial-value split moduli: provisional parameter calculation

2026-10-17. This is a new arithmetic refinement of the same-J parameter ledger, not an accepted hardness theorem or a new computational route. No probabilistic lemma or experiment is asserted. It does not change any frozen source, proof or claim.

The old factorial construction establishes polynomial bit length, but not polynomial value. A single least prime congruent to 1 modulo 2nT gives polynomial value from a primary Linnik bound, but does not by itself establish coprimality with every supplied D. The following residue-family construction addresses only that arithmetic gap.

Let n>=2 be a power of two, T>=1 an integer lower threshold, and D>=1 an integer ideal norm. Put r=floor(log2 D)+1, computed exactly as D.bit_length(), j0=floor((T-1)/(2n))+1, and a_i=1+2n(j0+i), 0<=i<r. Let M be the least power of two strictly greater than T+2nr. Then T<a_i<M, all a_i are odd, their residues modulo M are distinct, and 2n divides M. Moreover M<=2(T+2nr).

Use the published assertion that there is an absolute C for which each reduced progression a modulo M contains a prime at most C M^(26/5). For each a_i choose its least positive prime q_i in that progression. The q_i are distinct, q_i>T, q_i=1 modulo 2n, and q_i<=C[2(T+2nr)]^(26/5). At most floor(log2 D) distinct primes can divide D, since a product of r distinct primes is at least 2^r>D. Therefore at least one q_i is coprime to D. The conclusion also covers D=1.

This deduction uses the complete primary assertion as a hypothesis. The author's [Xylouris 2009 primary abstract, exact v1](https://arxiv.org/abs/0906.2749v1), inspected again at 23:54 UTC, states exponent 5.2 for coprime natural-number progressions. No explicit numerical value of C was retrieved, and no analytic-number-theory proof was reconstructed. This note consequently does not certify a numerical search cutoff or effective concrete parameter table from an unspecified C.

Given that primary theorem, exhaustive primality testing of integers q>T with q=1 modulo 2n and gcd(q,D)=1 terminates by the displayed polynomial upper bound in n,T,log D. Ordinary exact gcd and deterministic primality testing suffice; factoring D or factoring a factorial construction is unnecessary. This is an asymptotic uniform polynomial-time conclusion when T is polynomial in the input length. A fixed all-input implementation cap with numerical constants remains a separate obligation. Alternatively, a supplied q can be checked exactly for primality, splitting, threshold and coprimality without using the unspecified C at runtime.

The cryptographic quantifier is essential. This construction may select q as a function of J through D. A recovery algorithm promised useful success for only one fixed modulus cannot be assumed useful for the selected modulus. An application must promise success pointwise for each resulting q, or explicitly define and analyze the full joint public parameter distribution (q,J) before the fresh binary secret and errors. If q is published while J is hidden, its correlation with J is part of that joint law. Conditioning on a suitable q after observing secret-dependent data is not allowed. The same full metadata distribution must be retained in both challenge endpoints.

For D<=2^(rho n) and polynomial T, r=O(n), so this removes an arithmetic obstacle to polynomial-value moduli for a pointwise family. It does not map an arbitrary ideal to an eligible ideal, preserve a fixed-modulus recovery premise, establish a quantum circuit, or prove a standard hardness assumption. Existing source/comparator laws and all review gates remain unchanged.
