## Energy-rank transport: full endpoints and representation

For a source shell of size M and target shell of size N, when r is uniform in [0,M) and T is fresh uniform in [0,N), Nr+T is uniform in [0,MN). Each quotient floor((Nr+T)/M) has exactly M preimages, yielding a uniform target rank. For each fixed r the rule is also a normalized finite Markov row. Because the two source endpoint laws are uniform inside their energy shells, applying h to their shell masses and the rank rule proves their complete target laws. This conclusion is stronger than matching moments and rests on an exact conditional-uniformity premise. Fixed within-shell permutations preserve that premise.

The pair extension applies the same argument to sizes M_e0 M_e1 and N_f0 N_f1. It requires the relevant pair law to be uniform inside each joint shell, as inherited from the statement's "same statement" premise. Mapping only joint shell masses would not suffice for a general wrong-edge law; both the proof and scope warning state that separately. No full binary-cube endpoint is implied by this two-residual transport.

The DP recurrence counts every integer vector exactly. For |a|<=B, there are O(nB²) energies per layer and O(n²B²Q) additions, with single counts <=Q^n. Ranking and unranking scan the ordered alphabet and use these stored counts, so polynomial numeric Q,q,B give polynomial bit complexity. An exponentially large shell size is harmless here because only its polynomial-length binary count/rank is manipulated. It would not make shell enumeration polynomial.

The v2 pair-bit repair is correct: a single count uses at most n log2(max(Q,q))+1 bits; a product of two counts uses at most 2n log2(max(Q,q))+1. For n=2,I={-1,0,1}, the energy-one shell has 4 vectors, and its pair shell has size 16 and needs 5 bits. Thus the old single-shell bound cannot be read as applying unchanged to pair products. The finite control repeats this counterexample, verifies DP against enumeration for n=2,3,4, and verifies rank uniformity for all 256 pairs 1<=M,N<=16.

Rational h entries of polynomial encoding length and polynomial table size can be sampled exactly in expected polynomial time: a common denominator has bit length at most the sum of entry-denominator bit lengths, and integer rejection has expected fewer than two tries. An arbitrary real h table supplies only a mathematical kernel. Given an approximate row sampler, TV contraction through the exact rank stage transfers its per-row error without extra amplification. The statement properly separates these alternatives.

For wrapped discrete Gaussians, conditioning an integer coefficient on its centered representative interval changes its law by exactly its outside probability. Coupling and reducing modulo the modulus cannot increase that TV. A union bound over n coefficients, contraction through H, then the analogous target comparison give precisely the stated two-tail sum. If each modulus-to-width ratio is at least a fixed positive constant times n and widths have polynomial numeric size, the omitted mass is polynomial times exp(-Omega(n²)), hence negligible. This is a tail statement, not a moment match. Fresh calls conditional on one secret compose additively. No claim about the efficient construction of all necessary h tables follows.
