# BLIND-FRONTIER1 finite falsification registration v1

Registered before execution. No experiment is authorized by this file.

Requested job: one lightweight exact-arithmetic Python 3 process, no child jobs,
network, package installation, external data or solver. Limits: 120 seconds wall,
512 MiB address space, one process, one global experiment slot; preserve stdout,
stderr, exit, elapsed time and peak RSS under this reviewer directory.

1. CP-1: exact rational reconstruction of posterior masses, incidences, the
   two-hit event 21/2000 > 1/100, and residual posterior 21/221 < 1/10. The
   expected result rejects the sequential product claim.
2. Four-corner covariance identities: enumerate n=4,8 binary cubes and interior
   weight slices; verify exact signed-shift matrix identities on fixed rational
   positive-semidefinite covariance examples, including singular matrices and
   nonzero cross terms. Count the four-pattern coverage and compare with p_w.
   This checks identities/constants; it does not certify infinite Gaussian laws.
3. Finite-field source/decoder models: n=2,4,8, p=5,17,17 respectively; enumerate
   all proper nonempty root supports (at most 254), compute contractions and
   cyclic gaps, and verify the Fourier/GRS dimension, support, and minimum-distance
   statements using exact field arithmetic. Include consecutive odd supports and
   check their stabilizers; avoid enumeration exponential in field dimension.
4. ML/Bhattacharyya finite models: exact rational two- and three-point probability
   laws, checking TV versus affinity and one/two-sample likelihood event bounds.
   Square-root inequalities can be checked by exact squared rational expressions.

Outputs will include all chosen domains, full finite witnesses upon any failure,
and explicit limitations. No floating inference, random negative search, or
continuum-law certification is planned. If runtime would exceed 120 seconds,
the job stops and the remaining cases stay untested.
